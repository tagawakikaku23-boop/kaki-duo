# KAKI Duo

新潟の秋の贈りものを紹介する、2026年版の非商用柿パロディサイト。HTML / CSS / JavaScriptで動作します。

## 現行デザイン

- 左上は独自の黒い柿シルエット。タガワキカクの支給ロゴはフッターに小さく、CSSでグレー表示。原本画像は保持。
- スクロールに合わせてClosedからOpenへクロスフェードし、切り口が左右に開きます。上に戻すと閉じます。Closed/Openボタンでも操作可能です。
- 動きを減らす設定では画面固定・自動のスクロール連動を解除し、ボタンで静止画像を切り替えます。
- 長文を削減。製品仕様と食品の注意事項は折りたたみ表示。
- 「つくり手」「お求めいただけません。」の各セクションを削除。収穫ストーリーと写真待ちのラインアップ表示も省略。

## 編集するファイル

`index.html`、`styles-v3.css`、`script-v3.js`。

CONTENTS.md / DESIGN.mdは当初の仕様を原文保存したものです。現行画面については、今回のユーザー修正指示とこのREADMEを優先します。

## 画像

Closed / Openは組み込み画像生成ツールのAIイメージであり、実際の贈答品の写真ではありません。PNGが原本、WebPが配信用。生成条件はIMAGE_PROMPTS.mdに記録。ロゴはユーザー支給ファイルそのものです。

## 検証

375 / 768 / 1440pxで横はみ出しなし。スマホでスクロールによる開閉、逆方向で閉じること、メニュー、仕様表の開閉を確認。

## 柿のスペシャリスト

本人支給写真を組み込み画像生成ツールで表情・照明調整し、背景透過。右下に円形表示。写真を押すと案内を開き、閉じるボタン・Escape・パネル外で閉じます。「お召し上がりの前に」で注意事項を開きます。specialist.css / specialist.jsで管理。



## 収穫フォトストーリー

ユーザー支給の2025年の実写7枚を、製品体験の後へ追加。柿畑のスクロール拡大、収穫写真の控えめな登場、個性のある実、猫の見学風景へ続きます。photos.css / photos.jsで管理。画像はEXIF方向を反映し、配信向けにWebPを大小2サイズで保存。CSSで被写体に合わせてトリミング。人物・風景の生成や改変はしていません。動きを減らす設定では演出を解除します。


## 現在のコピー方針：秋の贈りもの

贈る相手を問わず楽しめる表現へ変更。ハロー、秋の実り。／新潟から届く。秋だけの体験。／秋の贈りもの。2026年モデル。を使用。品質の等級や選別・傷を強調する説明は掲載しません。製品サイト風のユーモア、スクロール開閉、実写7枚、HAYATOの案内は維持。初期のCONTENTS.md・DESIGN.mdより、この新方針を優先してください。

変更前はGitHubのbackup/pre-autumn-gift-2026-10-28ブランチに保存。復元時はこのブランチとmainを比較し、後続の変更を確認してから戻します。
